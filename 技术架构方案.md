## 二、核心数据库设计

### 2.1 用户与机构

```sql
-- 机构表（幼儿园）
CREATE TABLE organizations (
    id              BIGINT PRIMARY KEY AUTO_INCREMENT,
    name            VARCHAR(200)  NOT NULL COMMENT '幼儿园名称',
    logo            VARCHAR(500)  COMMENT 'Logo URL',
    province        VARCHAR(50)   COMMENT '省份',
    city            VARCHAR(50)   COMMENT '城市',
    contact_name    VARCHAR(50)   COMMENT '联系人',
    contact_phone   VARCHAR(20)   COMMENT '联系电话',
    plan_type       ENUM('free','basic','standard','flagship','group') DEFAULT 'free',
    plan_expire_at  DATETIME      COMMENT '套餐到期时间',
    monthly_quota   INT DEFAULT 5 COMMENT '每月配额',
    used_quota      INT DEFAULT 0 COMMENT '已用配额',
    wechat_openid   VARCHAR(100)  COMMENT '绑定微信',
    status          TINYINT DEFAULT 1 COMMENT '1-正常 0-禁用',
    created_at      DATETIME DEFAULT CURRENT_TIMESTAMP,
    updated_at      DATETIME DEFAULT CURRENT_TIMESTAMP ON UPDATE CURRENT_TIMESTAMP
);

-- 教师用户表
CREATE TABLE users (
    id              BIGINT PRIMARY KEY AUTO_INCREMENT,
    org_id          BIGINT        COMMENT '所属机构ID(个人用户为空)',
    nickname        VARCHAR(100)  COMMENT '昵称',
    avatar          VARCHAR(500)  COMMENT '头像',
    phone           VARCHAR(20)   COMMENT '手机号',

    wechat_openid   VARCHAR(100)  NOT NULL UNIQUE,
    personal_plan   ENUM('free','monthly','quarterly','yearly') DEFAULT 'free',
    personal_quota  INT DEFAULT 5,
    personal_used   INT DEFAULT 0,
    created_at      DATETIME DEFAULT CURRENT_TIMESTAMP
);
```

## 三、核心 API 设计

### 3.1 画作上传与预处理

```
POST /api/v1/artworks/upload
Content-Type: multipart/form-data

Request:
  - image: File (画作照片)
  - title: String (可选，画作名称)

Response:
{
  "code": 0,
  "data": {
    "artwork_id": 12345,
    "original_url": "https://oss.xxx.com/originals/xxx.jpg",
    "processed_url": "https://oss.xxx.com/processed/xxx.jpg",
    "status": "pending"
  }
}
```

### 3.2 动画生成

```
POST /api/v1/animations/generate

Request:
{
  "artwork_id": 12345,
  "style_code": "magic_fairytale",    // 风格编号
  "custom_prompt": "",                 // 自定义提示词(可选，PRO用户)
  "duration": 5                        // 视频时长(秒)，默认5秒
}

Response:
{
  "code": 0,
  "data": {
    "animation_id": 67890,
    "status": "queued",
    "estimated_time": 30               // 预计等待时间(秒)
  }
}
```

### 3.3 轮询生成结果

```
GET /api/v1/animations/{animation_id}/status

Response:
{
  "code": 0,
  "data": {
    "animation_id": 67890,
    "status": "completed",             // queued/generating/completed/failed
    "video_url": "https://oss.xxx.com/videos/xxx.mp4",
    "thumbnail_url": "https://oss.xxx.com/thumbs/xxx.jpg",
    "duration": 5.0
  }
}
```

## 四、阿里万象 API 对接方案

### 4.1 图生视频 API（核心）

```python
# 伪代码示例
import dashscope
from dashscope import VideoGeneration

def generate_animation(image_url, style_template, custom_prompt=""):
    """调用阿里万象 图生视频 API"""

    # 组装完整提示词
    full_prompt = build_prompt(style_template, custom_prompt)

    response = VideoGeneration.call(
        model="wanx-v1-image-to-video",
        prompt=full_prompt,
        negative_prompt=style_template.get('negative_prompt', ''),
        image_url=image_url,
        duration=5,          # 视频时长
        resolution="720p",   # 分辨率
        style=style_template.get('style_code')
    )

    if response.status_code == 200:
        task_id = response.output.task_id
        # 轮询任务状态
        return poll_task(task_id)
    else:
        raise Exception(f"API Error: {response.message}")

def build_prompt(style_template, custom_prompt):
    """组装提示词"""
    if custom_prompt:
        return custom_prompt
    return style_template['system_prompt']
```

## 五、图像预处理流程

```
原始照片（手机拍摄）
    ↓
① 透视校正（解决拍摄角度问题）
    ↓
② 边缘检测 + 自动裁剪（去除背景桌面）
    ↓
③ 色彩增强（提高画面饱和度、对比度）
    ↓
④ 尺寸归一化（调整为 API 最佳输入尺寸）
    ↓
⑤ 上传 OSS → 返回处理后的图片 URL
```

## 六、成本控制策略

| 策略 | 说明 |
|------|------|
| 分辨率分级 | 免费/低套餐用 480p，高套餐用 720p/1080p |
| 视频时长控制 | 基础用户 3 秒，高级用户 5-8 秒 |
| 自动降级 | API 排队过长时自动降级为预生成模板+画面合成 |
| 缓存复用 | 相同画作+相同风格不重复生成 |
| 队列削峰 | 批量生成时分批处理，避免瞬时高并发 |
| 阿里云折扣 | 签署年度框架协议，争取 7-8 折 API 价格 |
