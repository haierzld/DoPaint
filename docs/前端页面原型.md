# DoPaint 前端页面原型设计

> 技术栈：uni-app (Vue3) + Pinia + uView Plus  
> 目标平台：微信小程序（优先），后续可扩展到 H5/App

---

## 一、页面结构与路由

```
pages/
├── index/index              # 首页（画作列表 + 开始创作入口）
├── capture/capture          # 拍摄/上传画作
├── styles/styles            # 选择动画风格
├── generating/generating    # AI 生成中（进度动画）
├── preview/preview          # 动画预览 + 下载分享
├── gallery/gallery          # 班级画作画廊
├── profile/profile           # 个人中心
├── org-admin/org-admin      # 机构管理后台（园长/管理员）
├── plans/plans              # 套餐购买页
└── login/login              # 微信授权登录
```

## 六、关键交互细节

### 6.1 拍摄辅助引导

- 拍摄时显示半透明引导框，帮助老师对齐画作
- 自动检测画作边缘，拍摄后自动裁剪
- 光线不足时自动提示"请靠近光源"
- 支持从相册选择多张（批量模式）

### 6.2 生成状态反馈

- 实时进度条（倒计时）
- 粒子动画（让等待不无聊）
- 教育小知识轮播（利用等待时间）
- 生成失败自动重试（最多3次）
- 支持后台生成（可切换到其他页面）

### 6.3 视频预览

- 自动循环播放
- 支持全屏
- 左右滑动切换其他风格版本
- 长按保存到相册
- 一键分享到微信聊天

### 6.4 配额提示

- 首页顶部常驻配额进度条
- 剩余不足 20% 时变橙色预警
- 配额耗尽时弹窗引导购买
- 每次生成前显示消耗次数确认
